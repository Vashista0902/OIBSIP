# Car Price Prediction using Machine Learning

## Overview

This project predicts the selling price of used cars using machine learning regression algorithms. The dataset is cleaned, preprocessed, and analyzed before training predictive models.

## Objectives

- Clean and preprocess the dataset
- Perform feature engineering
- Explore relationships between vehicle features and selling price
- Train multiple regression models
- Evaluate model performance

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset

- **Dataset:** Vehicle Dataset from CarDekho
- **Source:** Kaggle

## Machine Learning Models

- Linear Regression
- Random Forest Regressor

## Project Workflow

- Data Loading
- Data Cleaning
- Duplicate Removal
- Missing Value Handling
- Feature Engineering
- Feature Encoding
- Exploratory Data Analysis
- Correlation Heatmap
- Model Training
- Model Evaluation

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Results

The Random Forest Regressor achieved better prediction performance compared to Linear Regression by capturing non-linear relationships within the data.
