# Unemployment Analysis with Python

## Overview

This project analyzes unemployment trends across India using Exploratory Data Analysis (EDA). The objective is to identify regional and temporal unemployment patterns and study the impact of the COVID-19 pandemic on unemployment rates.

## Objectives

- Load and inspect the dataset
- Perform data cleaning and preprocessing
- Analyze unemployment trends across states
- Visualize monthly unemployment patterns
- Compare unemployment before and after COVID-19
- Generate meaningful insights through data visualization

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

- **Dataset:** Unemployment in India
- **Source:** Kaggle

## Project Workflow

- Data Loading
- Data Cleaning
- Missing Value Analysis
- Data Type Conversion
- Exploratory Data Analysis (EDA)
- Time Series Analysis
- Correlation Analysis
- Pre-COVID vs Post-COVID Comparison

## Visualizations

- Region-wise Average Unemployment Rate
- Monthly Unemployment Trend
- Time Series Plot
- Top 10 States by Average Unemployment
- Correlation Heatmap
- Pre-COVID vs Post-COVID Comparison

## Results

The analysis highlights significant regional differences in unemployment rates and demonstrates the impact of the COVID-19 pandemic on employment across India.
