# 📊 Oasis Infobyte Data Science Internship (OIBSIP)

This repository contains the projects completed during the **Oasis Infobyte Data Science Internship (OIBSIP)**. These projects demonstrate practical applications of data analysis, machine learning, and natural language processing using Python and popular data science libraries.

---

# 📂 Projects

## 📈 Task 2 – Unemployment Analysis with Python

An exploratory data analysis project that examines unemployment trends across India, highlighting regional patterns and the impact of the COVID-19 pandemic.

### Features

- Data loading and preprocessing
- Missing value inspection and data cleaning
- Regional unemployment analysis
- Monthly unemployment trend visualization
- Top states comparison using bar charts
- Correlation heatmap
- Pre-COVID vs Post-COVID analysis
- Well-documented Jupyter Notebook

### Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 🚗 Task 3 – Car Price Prediction with Machine Learning

A regression-based machine learning project that predicts the selling price of used cars using various vehicle attributes.

### Features

- Data cleaning and preprocessing
- Feature engineering
- Exploratory Data Analysis (EDA)
- Feature encoding
- Correlation heatmap
- Train-test split
- Model training using:
  - Linear Regression
  - Random Forest Regressor
- Model evaluation using MAE, RMSE, and R² Score
- Feature importance analysis

### Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📧 Task 4 – Email Spam Detection with Machine Learning

A Natural Language Processing (NLP) project that classifies emails as Spam or Ham using text preprocessing and machine learning techniques.

### Features

- Text preprocessing
- Stopword removal and text cleaning
- TF-IDF Vectorization
- Train-test split
- Model training using:
  - Multinomial Naive Bayes
  - Logistic Regression
- Performance evaluation
- Confusion Matrix
- Accuracy, Precision, Recall and F1-Score analysis
- Clean and commented Jupyter Notebook

### Technologies Used

- Python
- Pandas
- Scikit-learn
- NLTK
- Jupyter Notebook
